# F1 Practice Analyzer

Marimo app analysing F1 practice sessions via [FastF1](https://github.com/theOehrly/Fast-F1): qualifying sims, long-run degradation, and an engine-mode sniff test (trap speeds vs each team's own qualifying baselines).

**Live snapshot:** https://glham.github.io/f1-practice-analyzer/ — static export of the latest analysed weekend.

Run it interactively: `python -m marimo run f1_practice_app.py` (needs `marimo`, `fastf1`, `matplotlib`, `pandas`).
